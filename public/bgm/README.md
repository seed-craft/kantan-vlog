# 内蔵BGM（音声ファイル）

ここに曲ファイル（MP3 / M4A）と `tracks.json` を置くと、アプリの「音楽（BGM）」に選択肢として出る。
`tracks.json` がない・空のときは、アプリが合成するオリジナル曲4種（`src/music.ts`）が出る。
曲を1つでも置くと、合成曲は選択肢から隠れる。

```json
[
  {
    "id": "honobono",
    "label": "ほのぼの",
    "desc": "家族のおでかけに",
    "file": "honobono.mp3",
    "credit": "Google Gemini（Lyria 3）で生成した曲です。家族や友だちに送る動画にも使えます。"
  }
]
```

- `label` は短く（ボタンに入る4〜5文字）。`desc` は小さく出る説明。
- `credit` は選んだときに表示。AIで作った曲は、人が作ったと誤解されない書き方にする（Googleの規約）。
- ファイルは1曲あたり数MBまでを目安に（スマホで開くたびに読み込むため）。曲は選んだときだけ読み込まれる。
